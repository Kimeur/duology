# API table

Every App Intents name this skill uses, checked in the iOS 27.1 simulator SDK on 20 October 2026: `AppIntents.swiftinterface`, the SwiftUI and UIKit overlays (`_AppIntents_SwiftUI`, `_AppIntents_UIKit`), and `AppIntentsTesting` in the iPhone Simulator platform of Xcode 27.1. Declarations are shortened. "iOS 26.0" means the SDK's `@available` says so (`anyAppleOS 26.0` in the interface).
