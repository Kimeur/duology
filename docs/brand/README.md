# Duology brand files

| File | Use it for |
|---|---|
| `logo.svg`, `logo-512.png` | App-icon style logo (dark tile). Avatars, listings, favicons. |
| `mark-light.svg` | The mark alone, for light backgrounds. |
| `mark-dark.svg` | The mark alone, for dark backgrounds. |
| `social-preview.png` | GitHub social preview (1280 × 640). |

The mark is an open phone seen from the front, with the dip where it folds. Keep its proportions, don't recolour the halves, and leave clear space around it at least as wide as one half's top edge.

Duology is not affiliated with Apple Inc. Don't combine these files with Apple logos or product images.
